Política de galetes.

Darrera actualització: 21 de novembre de 2026

1. Què són les galetes?

Les galetes (cookies) són petits fitxers que alguns webs desen al teu navegador per recordar informació sobre la teva visita.

2. Aquest web utilitza galetes?

Aquest web no utilitza galetes pròpies ni de tercers amb finalitats analítiques, publicitàries o de personalització. Per això no et mostrem cap avís de galetes.

  • Les tipografies estan allotjades al nostre propi servidor, de manera que no es connecta amb serveis externs per carregar-les.
  • Per saber de manera general quantes visites rep el web fem servir Cloudflare Web Analytics, una eina que no instal·la galetes ni identifica les persones usuàries.
  • El nostre proveïdor d'allotjament, Cloudflare, pot utilitzar de manera puntual galetes tècniques necessàries per a la seguretat del lloc (per exemple, per distingir persones de bots). Aquestes galetes estan exemptes de consentiment perquè són imprescindibles perquè el web funcioni de manera segura.

3. Com pots gestionar les galetes?

Pots veure, bloquejar o eliminar les galetes des de la configuració del teu navegador (Chrome, Safari, Firefox, Edge…). Bloquejar les galetes tècniques podria afectar el funcionament d'alguns webs.

4. Canvis en aquesta política

Si en el futur incorporem eines que utilitzin galetes, actualitzarem aquesta política i et demanarem el consentiment abans d'instal·lar-les.
